# Hero artwork

`winding-road.webp` is the text-free background for the homepage hero animation, shared by `index.html` and `coachsense.html`. Generated with the built-in image generation tool from the CoachSense Google Play feature artwork, then resized to 1120 × 1120 and encoded as WebP (quality 85). Labels, the brand icon, closing message and pause control are HTML/SVG, not embedded in the image.

The road stays still. The four pillars fade in sequentially during the first 20 seconds of a 30-second cycle; the closing message follows. Reduced-motion preferences show the static closing message. The pause control stops and resumes the cycle.

## Generation prompt

Use case: precise-object-edit. Edit target: supplied CoachSense Google Play artwork. Make a square website animation background derived from this artwork: preserve the distinctive winding orange road, peach sculpted landscape, pale warm cream sky, round sun, soft shadows and paper-like texture. Remove ALL text and logo completely. Reframe the road so it starts near the bottom centre and winds through the centre toward the sun near the upper right. Fill the square naturally with the same landscape; use generous pale cream space in the top left. This will sit behind small HTML pillar labels that appear along the road. No text, symbols, markers or new objects. Calm premium minimal composition; retain original palette and visual identity.
